# 鹈鹕单车漫游记 · Pelican Cruise 🚴✨

> 纯前端矢量 2D 互动动画与 Web Audio 程序化音乐装置。  
> 零外部素材依赖，单文件极速秒开。

在线体验网址：[https://lyzzhimmm.github.io/pelican-cruise/](https://lyzzhimmm.github.io/pelican-cruise/)

---

## 🌟 核心特性

- **矢量角色与物理逆运动学 (Inverse Kinematics)**
  - 双连杆骨骼逆运动学（2-Bone IK）计算，模拟真实腿部蹬踏动力学；
  - 膝盖向前破风屈伸，脚蹼自适应踏板角度；
  - 呆萌拟真的圆润身体、弹性微晃喉囊、自动眨眼系统与高速破风飞扬的红围巾；
  - 车头柳条车筐装有一台带经典红标的复古银黑旁轴测距相机（致敬摄影师阿志）。
- **3 套无限无缝循环视差场景**
  - 🌅 **落日海边 (Sunset Beach)**：暖金紫霞、海面波光、灯塔光芒、飞翔海鸥、剪影椰树林与木栈道；
  - 🌾 **恬静田野 (Rural Meadow)**：晨曦青山、随风旋转的复古风车、谷仓、木篱笆与向日葵花田；
  - 🏙️ **霓虹都市 (Cyber Twilight City)**：暮色天际线、红闪警示灯摩天楼群、发光店招（CAFE、PHOTO、JAZZ）、暖光街灯与柏油路面。
- **纯算法 Web Audio API 音频系统**（零 MP3 依赖）
  - 3 首场景专属 Lo-Fi / Chill 原创伴奏（Bossa Nova 电钢琴、清新马林巴木琴琶音、City Pop 律动低音）；
  - 逼真黄铜车铃（"Ding-Ding"）、链条机械棘轮咔嗒声、鹈鹕趣味互动叫声与场景环境底噪。
- **巡航挡位与交互**
  - 4 级车速：`0.5x 悠闲` / `1.0x 巡航` / `1.8x 疾速 (触发破风风线)` / `2.6x 狂飙`；
  - 实时仪表盘显示虚拟时速（km/h）、踏频（RPM）与累计骑行里程。

## ⌨️ 快捷键指南

| 按键 | 功能 |
| :--- | :--- |
| <kbd>Space</kbd> | 敲响清脆复古车铃 🔔 |
| <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | 快捷切换场景（海边 / 田野 / 城市） |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 增减骑行巡航挡位 |
| <kbd>M</kbd> | 开启 / 静音背景音乐 BGM |
| <kbd>S</kbd> | 开启 / 静音音效与环境音 |
| <kbd>F</kbd> | 全屏沉浸式体验 |
| 点击鹈鹕 | 触发憨萌台词与爱心/音符彩蛋 💛 |
